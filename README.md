# Crescendo Label

HID Crescendo cards and USB keys exist in different combinations, there is anofficial list of [FIDO certified](https://docs.hidglobal.com/crescendo/htog/aaguid.htm) identifiers.

It is also possible to know [details](https://docs.hidglobal.com/crescendo/api/c4000/select.htm#DataFieldReturnedintheResponseMessageforSELECTofACAInstance) of the firmware in the device.

This is a small App that shows basic information about the device in an easy to understand format.
